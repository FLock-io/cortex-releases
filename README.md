## What you can do

- Work with agents across your files and projects, using your own models and API keys.
- Create and edit documents, presentations, dashboards, and designs with your agent.
- Search local knowledge with citations, connect tools through skills and MCP, and run scheduled tasks with Cola.
- Record and transcribe meetings locally on macOS. Use model routing and usage insights to manage costs.
